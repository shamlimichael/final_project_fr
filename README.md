# final_project_fr

the project is an app meant  for selling collectable items between people 

the structure of the app is as following:

1.user - the user will have a balance of money, an inventory of all of the items he owns and orders he made and the listings he made. 

2.order - order will all of the info about the transaction that has been made for a listing on the site. it will include how much has a user paid and got and what item was traded.

3.listing - listing will have all of the info about the item that is being listed for sale, when an item is listed it will leave the inventory of the user that has listed the item and will show up on the store.

4.item - item will have all of the properties of the item: condition, type, name etc...
